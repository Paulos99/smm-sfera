## Как подать

**Если записи в реестре нет** — первичное уведомление:

1. Открыть [форму на pd.rkn.gov.ru](https://pd.rkn.gov.ru/operators-registry/notification/form/).
2. Войти через Госуслуги (учётная запись ИП) либо подписать УКЭП.
3. Заполнить поля из таблицы «Написать по факту сайта».
4. Отправить. Бумажную копию при подаче через Госуслуги обычно не дублируют.
5. Через срок до 30 дней проверить себя в [реестре](https://pd.rkn.gov.ru/operators-registry/operators-list/) по ФИО.

**Если запись уже есть** — уведомление **об изменении** (не новое первичное):

1. Тот же портал → уведомление об изменении сведений (приказ Роскомнадзора от 28.10.2022 № 180).
2. Войти как тот же оператор.
3. Внести только расхождения. Старые цели (кадры и т.п.) не стирать, если они по-прежнему верны.
4. Срок по ч. 7 ст. 22 152-ФЗ: не позднее 15-го числа месяца, следующего за месяцем, в котором изменились сведения.

Агент уведомление не подаёт.
